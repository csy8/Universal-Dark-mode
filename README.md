# Universal-Dark-mode
Force dark mode on any website using Ctrl+Q or Alt+Q.
Also accessible via the Tampermonkey icon menu.
Uses a global CSS override for maximum compatibility.

Ctrl+Q나 Alt+Q를 눌러 모든 웹사이트에서 다크 모드를 적용할 수 있습니다(네이버 등).
Tampermonkey 아이콘 메뉴를 통해서도 접근 가능합니다.
호환성을 극대화하기 위해 global CSS override를 사용합니다.
